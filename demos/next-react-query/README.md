# Next React Query Demo

Next.js and TanStack Query demo scaffold for RTRQ.

This demo will eventually show a browser client connecting to an RTRQ server with a public app ID and using the
React Query adapter to refetch invalidated queries.

## Commands

```sh
bun run dev
bun run build
bun run test
```

## Status

Scaffold only. No live RTRQ integration is implemented yet.
