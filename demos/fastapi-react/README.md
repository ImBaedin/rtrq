# FastAPI React Demo

Full-stack demo scaffold pairing a FastAPI backend with a React frontend.

The backend will use the Python server SDK with server URL, app ID, and API key. The frontend will use the
TypeScript client core or React Query adapter with server URL and app ID only.

## Projects

- `backend`: FastAPI backend scaffold.
- `frontend`: Vite React frontend scaffold.

## Status

Scaffold only. No live RTRQ integration is implemented yet.
