# FastAPI React Demo Backend

FastAPI backend scaffold for the full-stack RTRQ demo.

This backend will eventually mutate demo data and use `rtrq-server-sdk` to send invalidations to a standalone or
hosted RTRQ server.

## Commands

```sh
uv run rtrq-demo-fastapi-react-backend
uv run pytest demos/fastapi-react/backend/tests
```

## Status

Scaffold only. Demo mutations and RTRQ invalidation calls are not implemented yet.
