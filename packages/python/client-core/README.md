# rtrq-client-core

Reserved Python client core scaffold for future RTRQ client work.

This package exists so additional client families can follow the same monorepo conventions as TypeScript and
Python server packages.

## Security boundary

Client configuration includes the RTRQ server URL and app ID only.

## Commands

```sh
uv run pytest packages/python/client-core/tests
```

## Status

Scaffold only. Client behavior is not implemented yet.
