# @rtrq/shared

Shared TypeScript package scaffold for protocol-adjacent types used by RTRQ TypeScript packages.

Reserved responsibilities include query key typing, event envelope types, app identity types, and serialization
contracts that must remain stable across client adapters and server SDKs.

## Commands

```sh
bun run build
bun run test
bun run typecheck
```

## Status

Scaffold only. No runtime protocol behavior is implemented yet.
