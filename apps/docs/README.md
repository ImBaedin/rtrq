# RTRQ Docs

Documentation site scaffold for RTRQ.

This app will contain concepts, quickstarts, security guidance, SDK references, self-hosting instructions, SaaS
usage notes, and demo walkthroughs.

## Commands

```sh
bun run dev
bun run build
bun run test
```

## Status

Scaffold only. Documentation content is represented by placeholder metadata and a minimal Vite React app.
